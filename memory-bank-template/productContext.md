# Product Context — <nome-do-projeto>

## Por que existe

Dar ao desenvolvedor um fluxo disciplinado (ideia -> design -> plano -> codigo TDD ->
review) usando o Cline como executor do framework AIOX.

## Problemas que resolve

- Pular direto para o codigo sem entender o problema.
- Planos vagos sem arquivos exatos e verificacao.
- Codigo sem testes e sem review.

## UX / fluxo

1. Usuario descreve ideia -> brainstorm -> `docs/designs/<nome>.md`.
2. Design aprovado -> plano -> `docs/plans/<nome>.md`.
3. Plano aprovado -> implementacao TDD.
4. Review + verification antes de concluir.
5. Memory-bank atualizado ao final.
