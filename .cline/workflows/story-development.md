# Workflow: story-development

Desenvolver uma user story do inicio ao fim.
Convertido de `.aiox-core/workflows/story-development.yaml`.

## Como executar

"desenvolva a user story <descricao>".

1. **refine** (papel: scrum master) — skill `brainstorming`: refine a story com
   criterios de aceitacao.
2. **plan** (papel: scrum master) — skill `writing-plans`: divida em tarefas.
   Checkpoint: aprove o plano.
3. **implement** (papel: dev) — skill `test-driven-development`.
4. **review** (papel: QA) — skills `verification-before-completion`,
   `requesting-code-review`.
5. **finish** (papel: devops) — skill `finishing-a-development-branch`
   (PR/merge; sem push sem autorizacao).
